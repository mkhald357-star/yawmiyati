يومياتي — دليل سريع جداً
========================

هذا المجلّد جاهز للرفع كما هو. لا تُعِد ترتيب الملفات.

الخطوات الثلاث
--------------
1) أنشئ مستودعاً جديداً على GitHub باسم:  yawmiyati
2) ارفع محتويات هذا المجلّد كلها في جذر المستودع
   (مع المجلّدين المخفيّين .github و .well-known)
3) Settings ← Pages ← Branch: main / root ← Save

بعد دقيقة يعمل التطبيق على:
   https://mkhald357.github.io/yawmiyati/

افتحه بكروم على هاتفك ← القائمة ← «تثبيت التطبيق». انتهى.


تريد ملف APK؟
-------------
تبويب Actions ← «بناء تطبيق أندرويد» ← Run workflow
انتظر ٥ دقائق، ثم نزّل الـAPK من قسم Artifacts.

مهم: بعد أول بناء احفظ ملف keystore-base64.txt في
Secrets باسم KEYSTORE_B64 وإلا لن تستطيع التحديث لاحقاً.
التفاصيل في AUTOBUILD.md


الملفات
-------
index.html            التطبيق كاملاً
sw.js                 العمل بلا إنترنت والإشعارات المجدولة
manifest.json         اسم التطبيق وأيقوناته
icon-*.png            الأيقونات
twa-manifest.json     إعداد بناء الأندرويد
.github/workflows/    وصفة البناء التلقائي
.well-known/          ربط التطبيق بنطاقك (يحتاج بصمة التوقيع لاحقاً)

README.md             الشرح الكامل والنشر
ANDROID.md            طرق الحصول على APK
AUTOBUILD.md          البناء التلقائي خطوة بخطوة


ملاحظة عن .well-known
---------------------

إزالة شريط المتصفّح، انقله إلى مستودع باسم mkhald357.github.io
ليصير رابطه:
   https://mkhald357.github.io/.well-known/assetlinks.json
